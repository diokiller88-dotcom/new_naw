# esdf

> 点云转导航地图（占据栅格与 ESDF）

## 功能概述

将先验点云转化为导航用地图，最终输出**占据栅格地图**与 **ESDF 地图**。

## 核心代码

### 全局地图生成流程

将先验点云转化为 `grid_info` 信息地图，处理步骤如下：

1. **剔除伪影层** —— 去除最底层点云。仿真建模点云存在伪影层，会将高台平台误判为障碍，导致不可通行。
   > （悲，被这个坑了大半个月）

2. **点云滤波与体素化** —— 对剔除后的点云进行 **SOR 滤波 + 降采样体素化**，采用低分辨率并映射 Z 轴占据情况至 128 位。
   > **已知问题**：里程计在室内走廊等无特征环境下会出现 Z 轴两侧漂移（ICP 点到面退化）。若要彻底解决，设想需重构里程计，将下位机车体位姿纳入考量，目前尚未完成。

3. **第一次投影** —— 根据 Z 轴占据情况，按占据率与高程差进行初次投影。

4. **高度差判定** —— 在第一次投影基础上，计算临近高度差，区分障碍物与高台平地。这样只要有坡度可通行，高台与地面即可连通，同时可剔除大坑。

5. **离散障碍连续化** —— 使用**欧式距离聚类**将离散障碍点转化为连续墙壁。

6. **生成 ESDF 地图** —— 最终转化得到 ESDF 地图。

### 局部增量地图

由于计算的是二维地图，降低发布频率至 10Hz 后，直接进行全局 ESDF 计算已足够。

增量更新策略：

- 设置**滑动窗口**，更新占据状态与 ESDF
- **占据地图**：采用**贝叶斯滤波**更新占据状态
- **ESDF**：在滑动窗口内计算，为防止局部 ESDF 冲掉全局先验，**取两者较小值**进行更新，最终反馈至全局地图

## Test 部分

运行脚本：

```bash
./testesdf.sh
```

### 测试逻辑

- 读取预先点云地图
- 基于 OpenCV 进行交互

### 交互操作

| 操作 | 效果 |
| :--- | :--- |
| **左键** | 删除占据格 |
| **右键** | 添加占据格 |
| **S 键** | 保存结果 |

### 输出文件

运行后会保存 4 张图像：

| 图像 | 内容 |
| :--- | :--- |
| 一次投影地图 | 首次投影结果 |
| 高度差地图 | 临近高度差判定结果 |
| 最终占据地图 | 最终占据栅格结果 |
| P 图 | 手动编辑后的结果 |

同时将占据栅格地图与 ESDF 地图保存为 TXT 文件，该文件可直接作为 `planner` 包的离线地图使用。

## Node 部分

节点运行命令：

```bash
ros2 run esdf esdf_node
```

### 运行模式

| 模式 | 说明 |
| :--- | :--- |
| **离线地图模式** | 使用预先生成的先验全局地图 |
| **里程计累积模式** | 使用里程计累积点云构建先验全局地图 |

### 数据订阅

- 订阅里程计发布的**实时点云地图**
- 订阅 `relocation` 包的**坐标系变换关系**

将点云转换至 MAP 坐标系下进行局部增量更新。

ESDF包（导航用地图）
核心代码：
将先验点云转化为以Z体素占据情况和栅格状态的信息地图（grip_info）作以下处理：
*将先验点云剔除最底层的点云（由于仿真建模点云有一层伪影层，导致高台平台被认定为障碍导致不可行（悲，被这个阴了大半个月））
*将剔除后的点云后SOR滤波+降采样体素化，采用低分辨率加映射Z占据到128位上。（其实有一点问题，就是里程计在室内走廊等无特征环境下会导致Z两侧的漂移（ICP点到面的局面）如果要解决，本人设想，必须重构里程计，将下位机中车体的位姿加入考量）
*根据Z的占据情况按占据率与高程差等进行第一次投影。
*在第一次投影的基础上，计算临近的高度差，来判断是障碍还是高台平地。（这样只要有坡度能上，则高台和地面可以连通，也可以剔除大坑）
*使用欧式距离聚类将离散的障碍点转化为连续墙壁。
*最后转化位ESDF地图

关于局部的增量地图（由于是计算二维的，其实只要降低地图的发布频率，10HZ进行的化，进行全局的ESDF计算已经完全够了）:
*设置了一个滑动窗口，更新占据和ESDF，占据地图采用贝叶斯滤波进行更新占据状态，ESDF则是计算滑动窗口计算，为了防止局部计算的ESDF冲掉全局先验的情况，采用取两者较小值来进行更新，最后将结果反馈到全局地图

TEST：通过testesdf.sh来运行，通过OPENCV进行交互，读取预先的点云图。支持手动P图，左键删除占据格，右键添加，按S保存。最后会保存4个图，一个是一次投影的地图，一个是高度差的地图，一个是最终的占据地图，还有一个是P的图。同时将占据栅格地图和ESDF地图保存为TXT。该图可以直接作为planner包的离线地图
NODE：通过ros2 run esdf_node来运行，有两种模式，采用离线的地图和里程计的累积地图作为先验全局地图。通过订阅里程计发布的实时点云地图和relocation的坐标系变化关系，将点云转化为MAP系下进行局部更新。

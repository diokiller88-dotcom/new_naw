# relocation

> 定位与重定位

## 功能概述

主要负责**初始全局重定位**与**局部实时定位更新**。

> **吐槽**：这个包存在较大问题，最核心的缺陷在于将重定位和里程计分离，导致局部实时定位更新逻辑很不合理。但重构 SLAM 工程量太大，暂时不考虑完成。

## 核心代码

### 重定位策略

- **全局粗定位**：采用 IRIS + KD-TREE 的近似 K 最近邻历史帧匹配
- **精准矫正**：采用 GICP（局部协方差加权）

> **注意**：当前代码历史帧的保存仅在初始时进行。若需加入路径更新功能，则需采用 IKD-TREE 进行实时更新。

IRIS 参考：[LiDAR-Iris](https://github.com/JoestarK/LiDAR-Iris)，本代码做了适当改动，效果可能不如原版 IRIS。

## Test 部分

运行 `testrelocation.sh` 脚本进行测试。

### 测试逻辑

代码的重定位基于**在先验全局地图中采集关键帧**作为全局定位依据，支持以下两种方式：

- **手动添加**关键帧
- **自动均匀采样**关键帧

> 若不存在 `history_db.txt` 文件，运行 TEST 时会自动进行均匀采样生成历史关键帧。

### 交互操作

| 操作 | 效果 |
| :--- | :--- |
| **右键** | 添加历史关键帧（仅限空地，具体判断逻辑见代码实现与先验 PCD 文件） |
| **左键** | 删除已有的历史关键帧（蓝点） |
| **S 键** | 保存当前关键帧并进入测试 |

### 测试流程

1. 在地图任意位置点击模拟实际位姿
2. 拖动滑动模拟实际朝向
3. TEST 中会给定一定偏移参数进行模拟

### 可视化颜色说明

| 颜色 | 含义 |
| :--- | :--- |
| **红色** | 实际给定结果 |
| **黄色** | IRIS 粗定位结果 |
| **绿色** | GICP 精匹配结果 |

> **注**：测试数据为 RM26 赛季的仿真建图点云。为兼容 MID360 在局内的范围精度、位置视野，以及场内相对往年的退化情况，将 MID360 在 IRIS 中的分辨率和相关参数适当调高，实际可以调整。该 TEST 文件仅用于离线演示效果。

## Node 部分

节点运行命令：

```bash
ros2 run relocation relocation_node
```

## Scan Context++ 与 IRIS 融合

粗定位使用 IRIS Top-80 与 SC++ Top-20 候选并集和双描述子融合排序，
再沿用原有 GICP 候选验证。完整测试会自动生成 `history_db_sc.bin`，使用说明见
[`SCAN_CONTEXT_PLUS_PLUS.md`](SCAN_CONTEXT_PLUS_PLUS.md)。

### 运行模式

| 模式 | 说明 |
| :--- | :--- |
| **离线模式** | 在 RViz 中使用 `2D Pose Estimate` 可模拟 TEST 的测试 |
| **实时接收里程计模式** | 获取先验点云之前存在手动设置的先验点（详见代码）；使用 `2D Pose Estimate` 可修改该起始点。若 `planner` 包同时运行，也会同步修改起始点 |

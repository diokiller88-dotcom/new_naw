relocation包，主要用初始全局重定位与局部实时定位更新
吐槽:这个包有很大的问题，最主要原因在于将重定位和里程计分离，导致局部实时定位更新很不合理。但是重构SLAM工程量太大，暂时不考虑完成


核心代码:
重定位:全局粗定位采用IRIS+KD-TREE的近似K最近邻历史帧，精准矫正采用icp（SVD分解），当前代码历史帧的保存只有在初始时候有，如果需要加入路径更新的则需要采用IKD-TREE去实时更新
（IRIS参考https://github.com/JoestarK/LiDAR-Iris,本代码做了适当改动，效果可能不如原版IRIS）


test部分:
运行testrelocation.sh指令
（注:代码的重定位主要基于在先验全局地图采集关键帧作为全局定位的要求，可以手动添加和自动均匀采样。均匀自动采样的办法就是在运行TEST之前，删除history_db.txt会自动进行均匀采样。）
若未有history_db.txt文件则会生成先均匀采样历史点。然后左键删除已有的历史关键帧（蓝点），右键添加（只能在空地上添加，判断哪里为空地的具体看代码实现与先验PCD文件）。按S保存并且进入测试。
测试，在地图任意位姿点击（模拟实际的位姿）并且滑动（模拟实际的朝向），在TEST中会给定一定偏移参数模拟。红色为实际给出结果，黄色为IRIS粗定位得到，绿色为ICP精匹配得到的结果。
（注，测试中为RM26赛季的仿真建图点云，在局内为了兼容MID360的范围精度和位置导致的视野，以及场内相对于往年退化的情况将分辨率和MID360在IRIS中给高，实际可以调整，该TEST文件只是为了离线演示效果）

node部分:节点运行，ros2 run relocation  relocation_node。分为实时接收里程计模式和离线模式，离线下在RVIZ中打开2d pose estimate可以模拟TEST的测试;实时接收里程计模式下，在获取先验点云之前会有手动设置的先验点（具体阅读代码），使用2d pose estimate可以修改该起始点（如果同时有planner包运行，也会同步修改起始点）

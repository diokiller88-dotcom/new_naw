planner包（规划器）
核心代码:
在ESDF下寻路和避障。
全局规划:JPS+LBFGS+ASTAR+MINCO。
*使用JPS进行进行第一步寻路，使用LBFGS将JPS跳点推动进行第一次优化，再通过采样路径点进行二次优化。第一次优化主要是避障，第二次优化主要是路径更加丝滑，最后使用MINCO对二次优化的结果进行轨迹表达。
*其中ASTAR算法主要是解决在通道两侧如果有横向墙壁时候第一次优化后，一侧如果是斜向则会将跳点推入横向墙壁后面，导致两个跳点的连线会穿过墙壁，这时候采用A_STAR将两跳点之间进行寻找新路径
重规划:采用双端进行重规划（即改变起点和改变终点），逻辑相似。
*使用AABB树划分+牛顿法来寻找新点与原路径的三阶多项式表达式中最近的一段的投影点。
*计算新点和投影之间的关系满足以下：当新点和投影点之间的距离超过某大阈值，则一定触发全局重规划；新点和投影点能无障碍直连且距离小于某小阈值，则不进行重规划，直接将新点与投影点向量累加到多项式的切向速度上；当新点和投影点之间不可达时候，先在路径上从投影点往前取第N段的点，将新点与前取点，采用ASTAR进行两点寻路，如果距离小于一定值，则对ASTAR的寻路采用局部轨迹优化，大于该值则直接进行全局重规划。（局部重规划：对ASTAR寻路的点采用第二次优化，并且拼接替代原来的路径点）
test文件中测试，30M的路，全局重规划最多不到40MS，局部重规划则是10MS以内

test文件：使用testplanner.sh脚本运行。
通过读取预先设定好的ESDF图（由ESDF包生成），基于OPENCV进行交互。运行后，左键选择初始点，右键选择终点，按J使用JPS寻路，按A使用ASTAR寻路，（但是只有第一次会涉及），按空格进行寻路，如果路径不可达，则可以再次寻路。（如果在墙壁里面应该进行BFS找最近的可通行路的，但是没写，后面有时间再写吧）
寻路成功会出现三条轨迹，分别对应了一次寻路（蓝色），一次轨迹优化（跳点，绿色），二次轨迹优化（采样点，紫色）。同时会弹出另外一个窗口，在该窗口上左键修改起点，右键修改终点，同时在终端会打印重规划耗费的时间


node文件：通过ros2 run planner planner_node运行。有两个模式，一个是订阅离线地图，一个是订阅实时话题发布的地图。起点和终点的位置则是依据话题的更新来决定。当能获取其他话题发布的起点（relocation包，同relocation包相同，如果没有的话会有一个先验的起点）和终点（下位机包）时候，则使用其他话题发布的内容，其他情况下则是使用RVIZ中的点进行手动设定，2d pose estimate为起始点（如果同时在RVIZ订阅relocation包的话也会同步更改），2d goal pose为终点。（暂时不支持设定中间路径点）只会在RVIZ中显示最后MINCO的路径轨迹。

# planner

> 规划器

## 功能概述

在 ESDF 地图下进行**寻路**与**避障**。

## 核心代码

### 全局规划：JPS + LBFGS + ASTAR + MINCO

处理流程如下：

1. **JPS** —— 第一步寻路，生成初始跳点路径
2. **LBFGS（一次优化）** —— 推动 JPS 跳点进行第一次优化，主要实现**避障**
3. **LBFGS（二次优化）** —— 对采样路径点进行第二次优化，主要使路径**更加丝滑**
4. **MINCO** —— 对二次优化结果进行**轨迹表达**

> **ASTAR 的补充作用**：当通道两侧存在横向墙壁时，一次优化后若一侧为斜向，会将跳点推入横向墙壁后方，导致两跳点连线穿过墙壁。此时采用 A* 在两跳点之间重新寻路。

### 重规划

采用**双端重规划**（改变起点 / 改变终点），两端逻辑相似。

**核心步骤**：

1. 使用 **AABB 树划分 + 牛顿法**，寻找新点与原路径的三阶多项式表达式中最近一段的投影点
2. 根据新点与投影点的关系，分级处理：

| 条件 | 策略 |
| :--- | :--- |
| 距离 **超过大阈值** | 直接触发**全局重规划** |
| **可无障碍直连** 且距离 **小于小阈值** | 不重规划，将新点与投影点向量累加到多项式切向速度上 |
| **不可达** | 从投影点往前取第 N 段路径点，新点与该点之间采用 **A\* 寻路**。若距离小于一定值则进行**局部轨迹优化**；大于该值则直接**全局重规划** |

> **局部重规划**：对 A* 寻路点进行二次优化，拼接替代原路径对应部分。

### 性能指标

- **全局重规划**（30m 路径）：< 40ms
- **局部重规划**：< 10ms

### 参考

[GCOPTER - ZJU-FAST-Lab](https://github.com/ZJU-FAST-Lab/GCOPTER)

## Test 部分

运行脚本：

```bash
./testplanner.sh
```

### 测试逻辑

- 读取由 `esdf` 包预先生成的 ESDF 地图
- 基于 OpenCV 进行交互

### 交互操作

| 操作 | 效果 |
| :--- | :--- |
| **左键** | 选择初始点 |
| **右键** | 选择终点 |
| **J 键** | 使用 JPS 寻路（仅首次涉及） |
| **A 键** | 使用 A* 寻路（仅首次涉及） |
| **空格键** | 开始寻路。若路径不可达，可再次寻路 |

> **已知不足**：若点位于墙壁内部，应进行 BFS 寻找最近可通行路径，但目前尚未实现，后续有时间再补充。

### 可视化颜色说明

寻路成功后会显示三条轨迹：

| 颜色 | 含义 |
| :--- | :--- |
| **蓝色** | 一次寻路（JPS / A*） |
| **绿色** | 一次轨迹优化（跳点） |
| **紫色** | 二次轨迹优化（采样点） |

同时会弹出另一窗口，在该窗口上：

- **左键**修改起点
- **右键**修改终点
- 终端会打印重规划耗时

## Node 部分

节点运行命令：

```bash
ros2 run planner planner_node
```

### 运行模式

| 模式 | 说明 |
| :--- | :--- |
| **订阅离线地图** | 使用预先生成的地图 |
| **订阅实时话题地图** | 接收实时发布的地图 |

### 起点与终点来源

| 条件 | 来源 |
| :--- | :--- |
| 接收到其他话题发布的起点（`relocation` 包）和终点（下位机包） | 使用话题内容 |
| 无话题发布 | 使用 RViz 中手动设定：`2D Pose Estimate` 为起点，`2D Goal Pose` 为终点 |

> - 若 RViz 同时订阅了 `relocation` 包，起点会同步更新
> - 暂不支持设定中间路径点
> - RViz 中仅显示最终 MINCO 的路径轨迹
